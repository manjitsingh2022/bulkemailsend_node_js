# 📧 Bulk Email Sender (Node.js)

This project helps you send **bulk HTML emails** using **Node.js** and **Gmail SMTP**. You can load email recipients from a static file (`recipients.js`) or fetch them dynamically from a MySQL database.

---

## 📦 Features

- ✅ Send bulk emails with one command
- 📨 Supports HTML email templates
- 🔐 Uses `.env` for secure credentials
- 🐌 Supports throttling to avoid spam detection
- 🗃 Load recipients from file or MySQL
- 🧪 Logs success and errors clearly
